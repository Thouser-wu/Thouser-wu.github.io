软件避免安装C盘，Ollama避C盘完整安装迁移教程#

一、C盘爆红意味着什么#

1. C盘爆红的含义#

C盘是电脑系统盘，承载Windows系统文件、系统缓存、注册表、用户配置、软件默认安装目录、模型缓存、日志文件等核心数据。 C盘爆红，就是C盘存储空间即将占满、剩余空间严重不足，本质是系统盘资源被各类软件、缓存、大模型文件过度挤占。

2. 软件全装C盘的后果#

  1. 电脑严重卡顿、开机变慢 系统运行、虚拟内存读写都依赖C盘剩余空间，C盘爆满后虚拟内存无法正常调度，打开软件、切换窗口、开机进系统都会明显卡顿，甚至鼠标拖动都有延迟。

  2. 系统更新失败、功能异常 Windows自动更新、系统补丁安装需要占用C盘临时空间，空间不足会直接更新失败；还会出现应用闪退、弹窗报错、自带工具无法打开等问题。

  3. 重装系统数据全丢失 一旦系统崩溃需要重装，默认会格式化C盘。所有装在C盘的软件、模型文件、配置数据会直接清空，无法找回，迁移成本极高。

  4. 软件臃肿堆积、难以清理 多数软件默认把缓存、日志、离线资源存在C盘用户目录，日积月累产生大量隐形垃圾；手动清理容易误删系统文件，导致系统损坏。

  5. 大模型软件直接撑爆C盘 像Ollama、AI绘图、本地大模型这类软件，单个模型动辄几GB甚至几十GB，默认自动存C盘，装两三个模型就会直接把C盘撑红，这也是很多人C盘莫名爆红的主要原因。

二、以Ollama为例：默认装C盘的坑#

Ollama是本地大模型运行工具，很多新手习惯用官方一键命令安装：

irm https://ollama.com/install/windows | iex

这个命令强制默认安装到C盘，不仅程序本体占用C盘，后续ollama pull下载的所有大模型，都会自动存到C盘用户隐藏目录。

弊端非常明显：

  • 程序占用C盘程序空间，日积月累更新扩容越占越多；
  • 大模型文件体积巨大，几个模型就能直接把C盘占满；
  • 后期想迁移极其麻烦，不设置环境变量还会重复下载模型。

三、还没装Ollama：全新安装，全程避开C盘#

1. 官方下载安装包#

浏览器访问下载地址，手动下载安装包： https://ollama.com/download/windows

将 OllamaSetup.exe 放到 D:\安装包 这类非C盘目录备用。

2. PowerShell管理员安装到D盘#

以管理员身份打开PowerShell，依次执行以下命令：

# 1. 在D盘创建Ollama安装目录
mkdir D:\ollama

# 2. 切换到安装包存放目录（自行改成你的实际路径）
cd D:\安装包

# 3. 指定安装路径，直接安装到D盘，不占用C盘
.\OllamaSetup.exe /DIR="D:\ollama"

执行完成后，Ollama程序本体直接安装在 D:\ollama，完全脱离C盘。

3. 设置模型存储到D盘（最关键步骤）#

模型是占用空间大户，单独配置目录彻底杜绝C盘爆满：

# 1. 在D盘创建模型专属文件夹
mkdir D:\ollama\models

# 2. 设置系统环境变量，永久指定模型存放路径
setx OLLAMA_MODELS "D:\ollama\models" /M

重启电脑生效，后续所有ollama pull下载的模型，都会自动保存到D盘。

四、已经装在C盘？完整迁移到D盘教程#

如果已经用一键命令装在了C盘，按以下步骤无损迁移，不用重装、不丢模型。

1. 停止Ollama进程#

任务栏右键退出Ollama，或打开任务管理器，结束 ollama.exe 所有进程。

2. 迁移程序本体到D盘#

把C盘默认安装目录：

C:\Users\你的用户名\AppData\Local\Programs\Ollama

整个文件夹剪切，粘贴到：

D:\ollama

3. 修改系统环境变量Path#

  1. 搜索打开「编辑系统环境变量」→ 环境变量；
  2. 在系统变量找到 Path 并编辑；
  3. 删除旧的C盘Ollama路径；
  4. 新增路径：D:\ollama，保存确认。

4. 迁移已有模型文件#

把C盘默认模型目录：

C:\Users\你的用户名\.ollama\models

整个剪切迁移到：

D:\ollama\models

5. 配置模型路径环境变量#

管理员PowerShell执行命令，锁定模型存放目录：

setx OLLAMA_MODELS "D:\ollama\models" /M

重启电脑，迁移全部完成。

五、验证是否安装/迁移成功#

重启后打开PowerShell，执行以下命令校验：

# 查看版本，验证程序是否正常运行
ollama -v

能正常输出版本号，说明程序配置无误。

再拉取一个测试模型：

ollama pull deepseek-r1:1.5b

下载完成后进入 D:\ollama\models，能看到模型文件，代表程序、模型全都在D盘，不再占用C盘。

六、总结#

  1. C盘爆红根源：系统盘空间被软件、大缓存、本地模型无节制占用，会导致电脑卡顿、系统崩溃、更新失败；
  2. 所有大型软件、AI工具、开发程序一律不要装C盘，优先D盘/E盘；
  3. Ollama切忌用 irm | iex 一键安装，强制锁死C盘；
  4. 核心关键：用 /DIR 指定程序安装路径，配置 OLLAMA_MODELS 环境变量指定模型路径，彻底解放C盘空间。
