软件避免安装C盘

软件避免安装C盘，Ollama避C盘完整安装迁移教程 一、C盘爆红意味着什么 1. C盘爆红的含义 C盘是电脑系统盘，承载Windows系统文件、系统缓存、注册表、用户配置、软件默认安装目录、模型缓存、日志文件等核心数据。 C盘爆红，就是C盘存储空间即将占满、剩余空间严重不足，本质是系统盘资源被各类软件、缓存、大模型文件过度挤占。 2. 软件全装C盘的后果 电脑严重卡顿、开机变慢 系统运行、虚拟内存读写都依赖C盘剩余空间，C盘爆满后虚拟内存无法正常调度，打开软件、切换窗口、开机进系统都会明显卡顿，甚至鼠标拖动都有延迟。 系统更新失败、功能异常 Windows自动更新、系统补丁安装需要占用C盘临时空间，空间不足会直接更新失败；还会出现应用闪退、弹窗报错、自带工具无法打开等问题。 重装系统数据全丢失 一旦系统崩溃需要重装，默认会格式化C盘。所有装在C盘的软件、模型文件、配置数据会直接清空，无法找回，迁移成本极高。 软件臃肿堆积、难以清理 多数软件默认把缓存、日志、离线资源存在C盘用户目录，日积月累产生大量隐形垃圾；手动清理容易误删系统文件，导致系统损坏。 大模型软件直接撑爆C盘 像Ollama、AI绘图、本地大模型这类软件，单个模型动辄几GB甚至几十GB，默认自动存C盘，装两三个模型就会直接把C盘撑红，这也是很多人C盘莫名爆红的主要原因。 二、以Ollama为例：默认装C盘的坑 Ollama是本地大模型运行工具，很多新手习惯用官方一键命令安装： irm https://ollama.com/install/windows | iex 这个命令强制默认安装到C盘，不仅程序本体占用C盘，后续ollama pull下载的所有大模型，都会自动存到C盘用户隐藏目录。 弊端非常明显： 程序占用C盘程序空间，日积月累更新扩容越占越多； 大模型文件体积巨大，几个模型就能直接把C盘占满； 后期想迁移极其麻烦，不设置环境变量还会重复下载模型。 三、还没装Ollama：全新安装，全程避开C盘 1. 官方下载安装包 浏览器访问下载地址，手动下载安装包： https://ollama.com/download/windows 将 OllamaSetup.exe 放到 D:\安装包 这类非C盘目录备用。 2. PowerShell管理员安装到D盘 以管理员身份打开PowerShell，依次执行以下命令： # 1. 在D盘创建Ollama安装目录 mkdir D:\ollama # 2. 切换到安装包存放目录（自行改成你的实际路径） cd D:\安装包 # 3. 指定安装路径，直接安装到D盘，不占用C盘 .\OllamaSetup.exe /DIR="D:\ollama" 执行完成后，Ollama程序本体直接安装在 D:\ollama，完全脱离C盘。 3. 设置模型存储到D盘（最关键步骤） 模型是占用空间大户，单独配置目录彻底杜绝C盘爆满： # 1. 在D盘创建模型专属文件夹 mkdir D:\ollama\models # 2. 设置系统环境变量，永久指定模型存放路径 setx OLLAMA_MODELS "D:\ollama\models" /M 重启电脑生效，后续所有ollama pull下载的模型，都会自动保存到D盘。 ...

计算机中原码、反码、补码、移码总结 一、基本概念 在计算机中，分为有符号数和无符号数，有符号整数通常用最高位表示符号位： 0 表示正数 1 表示负数 以下均以 n 位二进制为例（含 1 位符号位）。 二、原码（True Form） 定义 最高位为符号位，其余位为数值的绝对值二进制。 计算规则 正数：符号位 0，数值位不变 负数：符号位 1，数值位不变 特点 表示直观，符合人类阅读习惯 0 有两种表示：+0 和 -0，取值范围为 $[-(2^{n-1}-1),\ 2^{n-1}-1]$ 减法运算复杂，计算机不直接用原码做加减 示例（8 位） +5 → 0000 0101 -5 → 1000 0101 +0 → 0000 0000 -0 → 1000 0000 三、反码（One’s Complement） 定义 原码的基础上，负数按位取反，正数不变。 计算规则 正数：反码 = 原码 负数：符号位不变，数值位逐位取反（0↔1） 特点 只是过渡编码，主要用于求补码 同样存在 +0 和 -0 两种表示,取值范围为$[-(2^{n-1}-1),2^{n-1}-1]$ 示例（8 位） +5 → 0000 0101（与原码相同） -5 → 1111 1010 +0 → 0000 0000 -0 → 1111 1111 四、补码（Two’s Complement） 定义 计算机实际存储和运算使用的编码。 ...

创建个人博客网站的流程

创建个人博客网站的流程 首先，创建自己的网站分为动态和静态两种类型。 动态网站 动态网站是指需要服务器端运行的网站，用户访问时需要服务器端处理，生成动态页面。动态网站通常使用 PHP、Node.js、Python 等后端语言编写，可以部署在 Heroku、AWS、Azure 等云平台。 基本流程 1. 准备工作 准备好一个域名 购买一台服务器，在阿里云和腾讯云等平台购买，个人博客的话轻量级服务器就足够了 2. 服务器购买与配置 注册和登录后，完成实名认证（个人 / 企业均可） 进入「轻量应用服务器」控制台，点击「新建」 3. 服务器基础配置 进入服务器实例详情页，记录公网 IP、管理员密码（忘记可在控制台重置） 开放端口：在「防火墙」标签页，添加规则开放 80、443、8888 端口（宝塔面板必备） 重置 root 密码（可选，确保登录安全） 4. 安装与配置宝塔面板 方式 1：一键镜像安装 进入实例「应用管理」页签，找到「宝塔 Linux 面板」，点击「访问」 复制面板登录地址（如 http://公网IP:8888/随机字符串）、用户名、密码 浏览器访问登录地址，首次登录需绑定宝塔账号，按提示完成初始化 面板设置：修改默认用户名、密码、面板端口（建议改为非 8888 的常用端口，提升安全性） 方式 2：手动安装（无镜像时使用） 用 SSH 工具（如 FinalShell、Xshell）连接服务器： 主机：公网 IP，端口：22，用户名：root，密码：重置后的 root 密码 执行安装命令（以 Ubuntu 系统为例，CentOS 需换对应命令） 运行以下命令： wget -O install_panel.sh https://download.bt.cn/install/install_panel.sh && sudo bash install_panel.sh ed8484bec 输入 y 确认安装，等待 5-10 分钟，记录面板登录信息 5. 搭建博客环境与部署 宝塔面板左侧「软件商店」，搜索安装「LNMP」套件（Nginx+PHP+MySQL，适合 WordPress） 左侧「网站」→「添加站点」，填写： 域名：你的博客域名（如 xxx.com，需先解析到公网 IP） 数据库：选择 MySQL，设置用户名、密码 其他默认，提交 安装博客程序（以 WordPress 为例）： 宝塔「软件商店」搜索「WordPress」，一键安装到站点目录 访问 http://你的域名/wp-admin，按提示完成博客配置（设置标题、账号、密码） 6. 域名解析与 ICP 备案 域名解析：进入域名服务商控制台，添加 A 记录，将域名指向服务器公网 IP ICP 备案：腾讯云 / 阿里云控制台进入「备案」模块，按提示提交资料（域名、身份证、服务器信息），等待审核通过后，博客即可正常访问 7. 安全与优化（可选） 宝塔「安全」模块：开启防火墙、暴力破解防护，设置 IP 白名单 配置 HTTPS：宝塔「网站→SSL」，申请免费 Let’s Encrypt 证书，强制 HTTPS 访问 博客优化：安装缓存插件（如 WP Rocket）、优化图片，提升访问速度 常见问题与避坑指南 宝塔面板无法访问：检查防火墙是否开放 8888 端口，确认服务器公网 IP 正确 博客访问慢：选就近地域服务器，开启 CDN（腾讯云 / 阿里云免费 CDN） 环境冲突：宝塔安装前确保系统纯净，无其他 Web 环境（如 Apache、Nginx） 静态网站 静态网站是指不需要服务器端运行的网站，所有的内容都是预先写好的，用户访问时直接从服务器上下载静态页面，不需要服务器端进行处理。静态网站通常使用 HTML、CSS 和 JavaScript 等前端技术编写，可以部署在 GitHub Pages、Netlify、Vercel 等平台上，比如我就是部署在github上，在cloudflare上托管。 ...
