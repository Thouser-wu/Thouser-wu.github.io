### 1. 查端口占用 PID
#### 1:把端口号换成你要查的，比如 8080、3306
```cmd
netstat -ano | findstr 端口号
```
输出最后一列就是 PID

2. 通过 PID 查是哪个程序
```cmd
tasklist | findstr PID号
```
3. 强制关闭占用端口的进程
```cmd
taskkill /F /PID PID号
```

#### 2：有时候端口是被 Windows 系统保留了，不是被程序占用，报权限禁止错误，例如：
```powershell
(HTTP code 500) server error - ports are not available: exposing port TCP 0.0.0.0:8001 -> 127.0.0.1:0: listen tcp 0.0.0.0:8001: bind: An attempt was made to access a socket in a way forbidden by its access permissions.
```
解决方法：以管理员身份打开 PowerShell，复制运行这 2 条命令：
```cmd
net stop winnat
net start winnat
```
